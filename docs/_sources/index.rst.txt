PressureMon Documentation
#########################

Welcome to the documentation for **PressureMon**, a battery-powered pressure
and temperature monitor for fermentation and beer storage. PressureMon reads
one or two pressure sensors, records temperature and battery status, and sends
measurements to external services over Wi-Fi or Bluetooth.

For project information, firmware downloads, and board options, visit the
`PressureMon project page <https://gravitymon.com/project-pressuremon.html>`_.
For initial installation, use the `GravityMon Web Flasher
<https://gravitymon.com/flasher/index.html>`_.

.. tip::

   Start with :doc:`installation`, then follow :doc:`intro` to set up Wi-Fi,
   calibrate sensors, and check the first readings.
